## Color de icono contextual

La variable `Icon Context/icon/color` tiene modos: `Default` → `text/primary`; `OnPrimary` → `primary/contrastText`; `OnSecondary` → `secondary/contrastText`; `OnSurface` → `primary/main`; `Disabled` → `text/disabled`; `Muted` → `action/active`; `OnNav` → `nav/text`; `OnError` → `error/contrastText`; `OnSurfaceError` → `error/main`. Resolver siempre el alias en el modo Light o Dark vigente.
