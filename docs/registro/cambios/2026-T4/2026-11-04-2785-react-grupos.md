# Cambio: transporte backend de grupos de aplicación (#2785, U07)

## Corte backend actual

Esta unidad incorpora únicamente los endpoints JSON de listado, alta y edición
de grupos, sus pruebas y el montaje de sus rutas. Reutiliza GroupForm y las
vistas originales; no modifica permisos, Admin, modelos, reglas de delegación,
exportación ni preferencias de columnas. No incluye el selector React ni su UI.
La verificación aislada pasa con 169 pruebas de grupos, cuenta, cambio
obligatorio, sesión y requisitos; Black en cuatro Python, Pylint y referencias
documentales. Persisten siete avisos previos. Se usó la imagen local fijada sin
red, código de solo lectura y datos SQLite sintéticos; sin navegador ni TCP.

Las 32 regresiones HEAD observaron dieciséis fallos internos y dieciséis casos
externos correctos antes de añadir únicamente las rutas de grupos al adaptador
admindocs propio. Los permisos de cada acción y requisitos se evalúan antes de
buscar el objeto. Se conservan los 401/403/200 y el 404 de objeto inexistente
para usuarios autorizados; no se impone un formato nuevo para ese error.

La comprobación independiente conserva 64 registros GET/HEAD por IP, ruta y
actor, 128 comparaciones directas del middleware y el digest del dominio sin
cambios, con sesiones intactas. Una expectativa errónea del verificador sobre
404 HTML interrumpió el primer intento: la respuesta observada era JSON. La
recuperación autorizada ejecutó solamente las nueve peticiones pendientes y los
controles faltantes, conservando los 55 registros originales sin repetirlos.
No cambió la aplicación ni se afirma paridad de formato404 no medida.

Los controles de middleware no son una suite HTTP adicional. Los dos blobs
corregidos coinciden con GREEN; no se confunden bytes CRLF del archivo Git con
blobs LF. Requiere revisión técnica por controles de acceso y middleware
compartido. No acredita paridad visual, aceptación humana, CI ni despliegue.

La autorización histórica del selector React no constituye una política nueva
de permisos. Las secciones siguientes conservan el registro del circuito
completo; sus pruebas, capturas y correcciones de frontend no son evidencia
nueva ni aceptación del corte backend actual.

## Alcance

Migración local de `/grupos/`, `/grupos/crear/` y `/grupos/editar/<id>/`,
con búsqueda, columnas, exportación, mensajes y retorno al listado.
No incluye Django Admin/Unfold #2789, nuevos permisos ni activación global.

El usuario autorizó expresamente que el selector React funcione para quienes ya
pueden crear o editar grupos, aunque el widget Django original falle para esos
actores. Esta diferencia intencional no modifica `/admin/jsi18n/` ni sus guardas.
La referencia sana se obtuvo con un superusuario sintético autorizado por las
guardas originales; conserva los textos mixtos `Choose`/`Remove` y los paneles
en español. No se declara idéntico al widget roto.

## Implementación

`usuarios/web_groups.py` adapta `GroupListView`, `GroupCreateView` y
`GroupUpdateView`. `GroupForm` conserva nombre obligatorio, limpieza y unicidad
sin distinguir mayúsculas, catálogo ordenado y permisos múltiples opcionales.
La propagación a miembros permanece en las relaciones y mecanismos originales;
no modifica delegaciones ni campos de Profile. Los endpoints de sesión aplican
requisitos previos y permiso específico antes de acceder al objeto.

`Groups.tsx` renderiza controles JSX desde metadatos tipados: ningún formulario
HTML de Django se inserta en React. Reutiliza estilos originales y el cliente
CSRF. Un resultado incierto bloquea reenvíos automáticos y no anuncia éxito.
Las preferencias siguen usando `/ajax/columnas-preferencias/` y el CSV conserva
`/grupos/exportar/`, incluido su comportamiento original respecto de la búsqueda.
Las entradas HTML React se habilitan solamente en la fábrica local de preview.

## Verificación

Se observaron RED públicos antes de implementar las rutas y controles. Las pruebas
propias focalizadas de API/entrada, frontend, tipos, lint, formato, build y
preservación del registro pasaron. La comparación real ejecutó una sola vez
las acciones de grupos y columnas, conservando checkpoints antes/después.
Una corrección propia consolidada resolvió el espaciado sin exportación,
la selección siguiente tras transferencia por teclado y el árbol lateral.
Sus regresiones observaron RED y luego GREEN; la revalidación real las confirmó.

El verificador independiente confirmó seguridad, ausencia de efectos en rechazos,
contratos nativos, recursos y lifecycle asíncrono. No encontró un defecto
funcional nuevo corroborado. La continuación acotada identificó la causa de los
residuos de pintura: faltaba preparar los contenedores de tabla con las clases
nativas de scroll. Se extrajo el hook existente de `InsumosList.tsx` a `useLegacyScrollHints.ts`
para reutilizarlo sin cambiar su algoritmo, incluyendo scroll, resize, cambios de columnas y limpieza
de observers/listeners. La regresión observó RED y luego GREEN junto a la prueba
existente de Insumos. El contrafactual temporal explicó también los residuos de
toast y modal; no se modificaron sus animaciones ni colores. El recheck independiente
limitado del candidato real, sin tratamientos DOM, confirmó los cuatro casos
retenidos: siete sectores con cero píxeles diferentes y cero diferencia geométrica
por carácter/rectángulo, con contenido, estilos efectivos y fuentes equivalentes.
El algoritmo extraído coincide exactamente con el hook anterior. Se retienen
metadatos de animación y propiedades heredadas sin efecto en estas capturas;
no se afirma que todas las propiedades CSS sean textualmente iguales.
