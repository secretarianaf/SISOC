# Cambio: compatibilidad de herramientas de desarrollo (#2804)

## Alcance

Se actualiza `requirements/dev.txt` de djlint 1.34.2 a 1.36.4 para instalar Black 26.10.1. Se conservan Pylint 3.2.6 y astroid 3.2.4 de la rama base. No cambia codigo de aplicacion ni datos.

## Causa y solucion

Black 26.10.1 necesita pathspec >=1.0.0, mientras djlint 1.34.2 exige pathspec >=0.12.0,<0.13.0. El pin de base en 1.0.0 hacia imposible instalar base y desarrollo juntos. djlint 1.36.4 elimina ese limite superior y conserva compatibilidad con los pins de click y json5 existentes. Se eligio esta actualizacion acotada en vez de djlint 1.43.2, que exigiria actualizar tambien click y json5.

La primera ejecucion de CI posterior a la correccion instalo las dependencias, pero Pylint 4.0.9 fallo con exit 26: elimino la opcion `suggestion-mode` vigente en `.pylintrc` e introdujo diagnosticos sobre codigo existente. Se difiere esa actualizacion mayor junto a astroid para una migracion dedicada. No se debilitan reglas ni se modifica codigo ajeno al alcance.

## Verificacion

- `uv pip compile requirements/base.txt requirements/dev.txt --python-version 3.11 --python-platform x86_64-unknown-linux-gnu`: antes fallo por pathspec (exit 1); despues resolvio todas las dependencias (exit 0).
- `uv pip compile requirements/lint.txt --python-version 3.11 --python-platform x86_64-unknown-linux-gnu`: exit 0.
- Instalacion aislada con Python 3.11.14 de todos los pins de desarrollo y los pins relacionados de base: exit 0; `uv pip check` confirma compatibilidad.
- Black 26.10.1, djlint 1.36.4 y Pylint 3.2.6 con astroid 3.2.4 arrancan correctamente. El resolvedor y la comprobacion de paquetes tambien pasan despues de diferir Pylint 4.
- `python -m djlint <plantilla-sintetica> --check --configuration=.djlintrc`: detecto formato incorrecto (exit 1) y acepto su version corregida (exit 0).
- No se agregan tests de aplicacion: el cambio solo corrige resolucion de dependencias, comprobada con el resolvedor real.
- No se ejecuto la suite Django ni el comando completo de Pylint: requieren el runtime completo; la instalacion real de Ubuntu y la validacion integral quedan a cargo de CI. No se desplego ni se solicito aceptacion funcional.

Risk: item 5 (dependencias de desarrollo; CI debe confirmar la instalacion y lint completos en Ubuntu).
